# Development workspace

This directory is the shared context layer for the repository's private development stage. It stores durable decisions, status, schemas, and compressed research notes so that work can continue across conversation windows.

It is **not** a chat archive and is not part of the intended public-facing awesome list. Before a public launch, review this directory and either remove it or retain only material that helps contributors.

## Reading order

1. [CONTEXT.md](CONTEXT.md) — stable project framing and topic map
2. [STATUS.md](STATUS.md) — current progress and immediate next steps
3. [DECISIONS.md](DECISIONS.md) — decisions and their rationale
4. [ENTRY_SCHEMA.md](ENTRY_SCHEMA.md) — per-work evidence fields
5. [TOPIC_WORKFLOW.md](TOPIC_WORKFLOW.md) — repeatable research process
6. [RESEARCH_BACKLOG.md](RESEARCH_BACKLOG.md) — open research questions
7. `topic-notes/` — working notes that are not ready for the README
